## How to use this file

Every prompt below contains the **exact filename to use for the generated image as a comment inside the prompt itself**, immediately after the prompt heading. **Do not rename the generated file.**

The workflow is:

**Generate → save using the exact filename in the prompt comment → copy the JPG into the exact folder → the wired website slot displays it automatically when the file exists.**

The website has been designed so that a missing future image does **not** create a broken-image icon, visible alt text, or a large empty image area. When the correctly named JPG is supplied, the corresponding image slot becomes visible.

## Global visual direction

JuliusOlugbade.com is a premium professional knowledge platform for Dr. Julius Olugbade. Imagery should communicate **professional authority, accounting, audit, finance, risk, compliance, leadership, research, teaching, professional knowledge and business reality**. It must feel credible enough for senior executives, boards, institutions, professional firms and serious commercial engagements.

Use contemporary Nigerian/African professional environments where appropriate. Prefer authentic editorial-corporate photography over generic stock-photo conventions. People should look natural, composed and intellectually engaged. Avoid exaggerated smiles, staged handshakes, artificial boardrooms, cliché calculators/coins, fantasy finance imagery and generic “successful businessman” visuals.

**Brand visual language:** Deep Royal Blue `#090C9B`, Strong Blue `#3066BE`, Powder Blue `#B4C5E3`, Warm Ivory `#FBFFF1`, with restrained neutral tones. The image should harmonise with the website rather than become a competing colour field.

**Identity rule:** whenever Dr. Julius Olugbade himself is requested, use the supplied approved reference image/identity reference where available. Do not invent a different person and label him Julius. Preserve authentic facial identity, age characteristics, skin texture and proportions.

**Text rule:** no readable generated text, fake company names, fake certificates, fake logos, fake statistics or fabricated document content. Screens/documents may contain intentionally blurred or abstract non-readable information.

## WEBSITE WIRING STATUS

The website HTML contains a dedicated image slot for each production asset. The slot is placed in the intended semantic page/section rather than appended to the bottom of the page.

### Home
- `jo-home-hero-01.jpg` → Home hero, right-side visual panel.
- `jo-home-advisory-01.jpg` → Home professional thesis / advisory capability section.
- `jo-home-audit-01.jpg` → Home selected professional experience / audit section.
- `jo-home-training-01.jpg` → Home academic authority / professional knowledge section.

### About
- `jo-about-portrait-01.jpg` → About primary profile block.
- `jo-about-professional-02.jpg` → About/Career professional experience.
- `jo-about-academic-03.jpg` → About/Education academic background.

### Critical implementation rule
The HTML references the exact JPG path. When the correctly named JPG is placed in that exact folder, it renders in the corresponding slot. Missing assets are removed by the image loader so they cannot create broken-image gaps.
